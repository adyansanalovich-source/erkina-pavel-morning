## GitHub Pages
Разместите index.html, style.css, script.js, config.js и папку assets в корне репозитория.
Settings → Pages → Deploy from a branch → main → / (root) → Save.

## Файлы
- index.html — текст и структура.
- style.css — оформление.
- script.js — конверт, искры, календарь, музыка.
- config.js — дата и персональные обращения.
- assets — фотографии, рамка и музыка.

Ссылка без параметров показывает «Дорогие друзья и родные!».
Персональные обращения можно добавить в WEDDING.guests в config.js:
'guest-code': { greeting: 'Уважаемая семья Ивановых!' }
Тогда персональная ссылка заканчивается на ?id=guest-code.
Неизвестный код также оставляет универсальное обращение.

Музыка запускается по нажатию на печать; кнопка позволяет включить или выключить её.
Этот репозиторий независим от первого свадебного сайта и версии в Sites.
